# Bazar Web App

## Разработка

### Тестирование WebSocket

В режиме разработки доступны инструменты для тестирования WebSocket событий через консоль браузера.

#### Предварительные требования

1. Откройте страницу с чатом (например, `/spaces/{spaceId}`)
2. Откройте консоль разработчика браузера (F12)

#### Доступные команды

##### Симуляция создания сообщения (CREATED)

```javascript
window.simulateWSEvent({
  type: 'CREATED',
  chatId: 1, // ID чата
  payload: {
    id: 999, // ID нового сообщения
    author:
      {
        userId: '1',
        firstName: 'Test',
        lastName: 'User',
        status: 'EXIST'
      },        
    content: 'Тестовое сообщение', // Текст сообщения
    createdAt: new Date().toISOString() // Время создания
  }
});
```

##### Симуляция удаления сообщений (DELETED)

```javascript
window.simulateWSEvent({
  type: 'DELETED',
  chatId: 1, // ID чата
  payload: {
    ids: [999, 998, 997] // Массив ID сообщений для удаления
  }
});
```

#### Примеры использования

**Создать тестовое сообщение:**
```javascript
window.simulateWSEvent({
  type: 'CREATED',
  chatId: 1,
  payload: {
    id: 999,
    userId: 'test-user',
    content: 'Привет из консоли!',
    createdAt: new Date().toISOString()
  }
});
```

**Удалить несколько сообщений:**
```javascript
window.simulateWSEvent({
  type: 'DELETED',
  chatId: 1,
  payload: {
    ids: [999, 1000, 1001]
  }
});
```

#### Важные замечания

- ⚠️ Эти функции доступны **только в режиме разработки** (`NODE_ENV === 'development'`)
- ✅ Убедитесь, что чат открыт перед использованием команд
- 📝 Все события логируются в консоль с префиксом `🧪`
- 🔄 Изменения отражаются в UI в реальном времени через React Query кэш

#### Отладка

Если команды не работают:

1. Проверьте, что вы находитесь на странице с открытым чатом
2. Убедитесь, что приложение запущено в режиме разработки
3. Проверьте консоль на наличие ошибок
4. Убедитесь, что `window.__testQueryClient` доступен (должен быть установлен автоматически)
