# Локальный запуск всей системы для теста фронта
1. Добавить host.docker.internal в /etc/hosts маппинг на 127.0.0.1 (НЕ ЗАБЫТЬ УДАЛИТЬ другую запись для этого хоста если ставили docker desktop)!!!1
2. Есть вероятность, что помешает файрвол: sudo systemctl stop ufw ИЛИ sudo systemctl stop nftables ИЛИ sudo systemctl stop firewalld
3. Зайти сюда https://github.com/Xatas-dev/bazar-k8s-charts/blob/master/bazar-infra/policies/space.yaml, скопировать оттуда space.yaml и вставить в папку devSandbox с именем space-policy.yaml 
3. Запустить docker-compose.yaml
    - Либо перейти в devSandbox и прописать docker-compose up (загуглите и скачайте прогу)
    - Либо в самой IDEA нажать на запуск в файлике docker-compose.yaml (зеленый треугольник сдвоенный)
4. Если все сделали правильно, то можно поднимать фронт и радоваться жизни
5. Заходим на http://localhost:5173

# Запуск хранилища файлов
1. Для работы вкладки Storage необходимо корректно запустить: bazar-files, bazar-storage, kafka, zookeeper, rustfs
2. После запуска необходимо зайти в админку rustFS (http://localhost:9001) и создать бакет с именем files. Вкладка "Браузер" в левой части -> "Создать бакет" - > Ввести имя (files) -> "Создать"
3. Далее в этой же админке заходим в "Назначение событий" -> "Добавить назначение событий" -> Выбираем Webhook -> Вводим URL в "Конечная точка Webhook" http://bazar-files:8080/webhook/files/file-uploaded -> Сохранить
4. В списке событий должно появиться событие со статусом online
5. Возвращаемся на вкладку "Браузер" -> Заходим в настройки созданного бакета -> Переходим на вкладку "События" -> "Добавить подписку на событие" -> Выбираем созданное нами событие и ставим галочку "PUT - Object upload" -> Сохранить
6. Проверяем вкладку Storage
